# 上下双屏配置：每屏有程序坞，浏览器留出空间

本文整理 EchoDock 现有功能在“外接屏在上、内建屏在下”场景中的组合用法。程序坞显示、原生 Dock 固定和窗口预留空间均来自 [EchoDock](https://github.com/baikaihao/EchoDock)，本文的贡献是配置流程与验证记录，没有修改应用源码。

## 适用场景与目标

保留符合实际位置的上下显示器排列，在下方内建屏使用原生 Dock，在上方外接屏使用 EchoDock。普通浏览器窗口填充屏幕时，为底部 EchoDock 留出空间。

| 屏幕 | 使用的程序坞 | EchoDock 开关 |
| --- | --- | --- |
| 下方内建屏 | 原生 Dock | 关闭 |
| 上方外接屏 | EchoDock | 开启 |
| 后续新接入的扩展屏 | EchoDock | 由“自动启用新连接显示器”决定 |

本指南针对底部程序坞。EchoDock 当前不提供左侧、右侧或顶部布局。投影仪须作为扩展显示器；镜像模式的从属屏幕不能独立承载另一个 EchoDock。

## 配置步骤

### 1. 保留正常的上下排列

在 macOS“系统设置 → 显示器”中，让排列与实际摆放一致。本方案不需要为唤出上方屏幕的原生 Dock，特意把两个屏幕错开成对角线。

从 [官方发布页](https://github.com/baikaihao/EchoDock/releases) 获取 EchoDock，并启动应用。从菜单栏图标打开“设置…”。

### 2. 授予所需的辅助功能权限

在 EchoDock“设置 → 通用”中申请辅助功能权限，再在 macOS“系统设置 → 隐私与安全性 → 辅助功能”允许 EchoDock。

这使应用能够检测及尝试固定原生 Dock，并调整符合条件的窗口大小。授权后重新打开 EchoDock 设置，确认权限状态更新。基本的额外程序坞显示不需要此权限，但下面的固定与窗口避让需要。

### 3. 分配两个程序坞，避免重叠

在 EchoDock“设置 → 显示器”中：

1. 将原生 Dock 策略设为“固定在所选显示器”，目标选择下方内建屏。
2. 检查内建屏的 EchoDock 开关为关闭。
3. 检查上方外接屏的 EchoDock 开关为开启。
4. 检查页面报告的原生 Dock 实际位置与固定状态。

选择固定目标时，应用本身已有默认分配和重叠提示；这里仍应检查最终状态。如果同一屏幕同时显示原生 Dock 和 EchoDock，就可能看到两层程序坞。

固定到非主显示器时，按原项目要求开启 macOS“显示器具有单独的空间”，并按系统提示重新登录。原生 Dock 固定是尽力而为的行为，不保证在所有系统和屏幕组合中永久生效。无法固定时，先检查权限、目标屏是否在线和上述系统选项；必要时切回“由 macOS 管理”。

### 4. 为浏览器窗口留出空间

在 EchoDock“设置 → 通用”中：

| 设置 | 本场景的选择 | 原因 |
| --- | --- | --- |
| 启用 EchoDock | 开启 | 显示程序坞 |
| 自动隐藏 | 关闭 | 窗口预留空间需要 EchoDock 常驻 |
| 为窗口预留空间 | 开启 | 让符合条件的普通窗口停在程序坞上方 |
| 全屏时自动隐藏 | 建议开启 | 全屏内容显示时隐藏该屏幕的额外程序坞 |

把浏览器移到上方外接屏，使用 macOS 窗口菜单中的“填充”，检查窗口底部与程序坞是否分开。这里的普通窗口填充与进入原生全屏空间不同。

原项目支持普通最大化窗口、左右分屏以及接触底边的标准分屏窗口。原生全屏、对话框、不可调整大小的窗口，以及拒绝辅助功能调整的应用不适用同样的调整规则。不要把“预留空间”理解为对所有窗口都保证避让。

### 5. 为新接入的投影仪或显示器启用程序坞

在“设置 → 通用”中开启“自动启用新连接显示器”。该选项针对新显示器首次连接；已连接过且被手动关闭的屏幕，仍应在“显示器”页面检查独立开关。

投影仪接入后，在 macOS 中选择扩展显示，并检查该屏幕上的 EchoDock 与普通窗口避让效果。全屏演示可能按“全屏时自动隐藏”设置隐藏程序坞。

EchoDock 必须保持运行。若希望登录后自动运行，可另外启用“登录时启动”；本次验证未覆盖重新登录后的自动启动。

## 验证记录与边界

以下记录来自 EchoDock **1.0.5** 的一次真实配置，未代表所有 macOS 版本、硬件或应用组合。

| 项目 | 证据范围 |
| --- | --- |
| 保留上下排列、上方外接屏启用 EchoDock | 已完成配置并核对 |
| 内建屏关闭额外程序坞、原生 Dock 固定目标 | 已核对配置；应用报告固定状态 |
| Chrome 移到上方外接屏后执行普通窗口“填充” | 已检查窗口填充结果，窗口高度为底部程序坞留出空间 |
| 自动启用新连接显示器 | 已核对设置开启 |
| 投影仪实际接入、第三屏、热插拔、合盖与睡眠唤醒 | 尚未实测 |
| 全屏隐藏、不同应用的分屏避让 | 功能范围依据原项目说明，未在本次逐项实测 |

复现时，建议继续检查：鼠标跨屏后是否重叠、普通窗口填充后是否遮挡、显示器重新连接后状态是否正确，以及退出 EchoDock 后的窗口行为。发现问题时，记录版本、扩展或镜像模式、屏幕相对位置、操作步骤和实际结果即可，无需上传完整系统报告。
